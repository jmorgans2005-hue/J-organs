# UBP.HYPER2 — Neon Dash

An original browser game by Andrew. Jump over hazards, collect gems, and play
through 700 generated levels. Minecraft-inspired colors are available from the
mode toggle.

## Play

Open the public game at <https://jmorgans2005-hue.github.io/J-organs/>.

## Controls

- Click, tap, or press **Space** to jump.
- Press **R** to restart the current level.
- Use the **MODE** toggle to switch the game's visual palette.

Progress and gems are saved in the browser.
